Choose a grouped 3MF or its corresponding STL set, not both for the same physical object. Read the multicolor notes and color-volume validation record.

  1. Select the machine's established multi-material profile and compatible materials with the technician. If it does not support this job, use the single-material STLs and painting instructions.
  2. Import all body color volumes together as one object with multiple parts. Import a wheel's color volumes together as another object with multiple parts. The exact command varies by slicer.
  3. Preserve shared coordinates. Some color volumes intentionally do not touch the bed. Do not arrange, center, scale or drop each color volume onto the bed separately; that can move details away from the body or wheel.
  4. Assign white, black, dark grey and red to the corresponding named volumes. Check the slicer's color preview; file names do not assign filaments automatically.
  5. Arrange one complete body upright and four complete wheels with visible faces up, all at 100% scale. Duplicate the complete wheel group to make four wheels.
  6. Inspect layers for gaps, overlaps and missing small color regions. Configure purge/flush amounts, any wipe tower, and supports for the actual machine. Include them in time, material and bed-space estimates.
  7. Print a multicolor wheel first to check black, dark-grey and red details. Print the detail coupon for structural features. Check the body's color boundaries in the layer preview before the full job.

A colored OBJ does not guarantee material assignments. The grouped 3MFs of the earlier revision of these files passed an import/export check in PrusaSlicer 2.9.6: each remained one object with three named color volumes, correct dimensions and relative positions, and no recorded repairs; the container format is unchanged, so repeat that import check on the college machine. PrusaSlicer did not retain the standard display colors, so manually assign and verify each named white, black, dark-grey and red region. Other slicers are untested; confirm grouping and shared positions or use the grouped STL alternative. This verifies file import, not a college-printer profile or physical print. Do not print a single-material part on top of its equivalent multicolor assembly.

Assembly and timing

Dry-fit all four wheels on a flat surface. Use equal-height temporary spacers to support the body's flat underside 6 mm above the table. Center each flat wheel back on its 11.2 mm round mounting pad, with the caliper relief toward the rear bumper. All four tires should touch the table. The labeled wheel files contain identical geometry, so any wheel fits any corner.

Apply a small amount of plastic-compatible adhesive to the bare contact faces; keep it away from visible surfaces. Keep the body supported and level while the joints set, then remove the spacers after curing. Check all four tires meet the same flat surface.

The wheels are fixed. Let paint and glue dry according to their product instructions before wrapping. Use a padded box to protect the mirrors and spoiler.

Three-day target: confirm the printer and run samples first; use the next print window for main parts; leave the final day for cleanup, paint and assembly. Machine availability, slicer estimates and the test result determine the real schedule. Drop tiny paint details before shortening assembly or drying time.

Single-material planning estimate only: the earlier revision's generic simulation gave about 8 hours 37 minutes and 104 g for one body and four wheels; the detail coupon adds about 14 minutes and 2 g (0.4 mm nozzle, 0.20 mm layers, simulated supports and skirt). This revision has the same footprint and 2 % less volume, so expect a similar figure. Multicolor time and material are unknown. The college slicer must include color changes, purge waste and the actual machine settings.
