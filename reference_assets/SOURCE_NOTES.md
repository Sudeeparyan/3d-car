# Source evaluation and attribution

Access checked 16 September 2026. Handoff notes updated 18 September 2026.

These are provenance and initial source-evaluation notes. The gift ZIP includes the original README and license; the downloaded source archive and original source meshes remain in the workspace reference folder. Current changes are recorded in `docs/ATTRIBUTION.md`, and current geometry checks are in `validation/`.

## Selected body source

**Ford Mustang GT 2018** by **SadPepe**.

- Original page: https://www.thingiverse.com/thing:3192801
- Files page: https://www.thingiverse.com/thing:3192801/files
- Creator: https://www.thingiverse.com/SadPepe/designs
- License shown on the source page: **Creative Commons Attribution-NonCommercial 4.0 (CC BY-NC 4.0)**, https://creativecommons.org/licenses/by-nc/4.0/
- The included `LICENSE.txt` also identifies SadPepe and Creative Commons Attribution-Non-Commercial.
- Retrieved using the normal, public **Download all files** button. No account or payment was required.
- Original archive preserved as `Ford_Mustang_GT_2018_3192801.zip`; unmodified extracted files are under `thingiverse_3192801/`.
- Archive includes `mustangBodyOnly.stl`, `MustangCompleteWithWheels.stl`, `wheel.stl`, `inner_wheel.stl`, README, license, and four preview images.

The creator's README describes a glued display model and says the updated source is approximately 140 mm long. Dimensions and topology must be verified from the actual mesh, not assumed from that description.

### Visual evaluation

The supplied previews show an identifiable 2018-style S550 fastback silhouette, long hood, closed window surfaces, twin hood vents, grille emblem, headlamps, panel lines, mirrors, and wheel arches. The surfaces are visibly faceted. Rear spoiler customization, mirror reinforcement, and physical print validation remain work for the adapted model. The source page labels the design a work in progress.

### Attribution for adaptations

If the body is used, preserve this credit alongside exported STLs, OBJ, Blender source, and printable instructions:

> Adapted from “Ford Mustang GT 2018” by SadPepe, https://www.thingiverse.com/thing:3192801, licensed under Creative Commons Attribution-NonCommercial 4.0, https://creativecommons.org/licenses/by-nc/4.0/. Modified for a 160 mm personal display model. See the project guide for the actual changes.

The final modification description must be updated to reflect the implementation. Do not imply the source creator endorses this adaptation. Keep the original README and license in the handoff archive. This source has a noncommercial restriction.

## Original source-wheel attribution

The Mustang README explicitly credits the wheels to **stunner2211**'s **ACR Viper Race Car**:

- Source: https://www.thingiverse.com/thing:3066426
- Creator: https://www.thingiverse.com/stunner2211/designs
- License independently verified on that page: **Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0)**, https://creativecommons.org/licenses/by-nc-sa/4.0/

Those wheel-source terms differ from the Mustang listing. If adapting or distributing the provided wheel meshes, preserve stunner2211's attribution and the applicable NC-SA terms. The final implementation uses independently generated fixed wheels. No source-wheel geometry is used in the final wheels or their multicolor regions. The unmodified reference archive remains preserved in the workspace, outside the gift ZIP.

## Validation boundary

These notes evaluate legitimate access, provenance, and source preview appearance only. They do not certify manifoldness, minimum thickness, printer compatibility, support layout, or successful physical printing. Those checks must refer to the final adapted model.
